What JobTruth looks for

The score starts at 100. Each warning sign subtracts points and each reassuring sign adds some. You always see the reasons, never just a number. Score 70 or more looks safe, 40 to 69 is suspicious, below 40 is high risk.

Asks for a registration, security or training fee−40
UPI ID or bank details mentioned−25
Personal email such as Gmail or Yahoo−20
Only reachable on WhatsApp or Telegram−15
Job promised with no interview−15
Salary too high for a fresher−15
Lookalike domain, such as infosys-careers.com−15
Pressure and urgency words−10

How your offer letter is protected

Offer letters contain your name, phone number and salary, so they are treated as private documents.

Private and encrypted

The bucket blocks all public access, encrypts every file at rest, and refuses any connection that is not HTTPS.

Tamper-evident

A SHA-256 fingerprint is sent with each file and verified by S3. Versioning keeps earlier copies if a file is overwritten or deleted.

Short-lived access

The server uses a role with the minimum permissions and no stored keys. Download links expire after 5 minutes, and files are deleted after 30 days.
